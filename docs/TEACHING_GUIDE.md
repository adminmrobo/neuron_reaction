# 강의자용 가이드 — 뉴런 반응 연구실 v2.0

대상: 대학 '딥러닝 기초', 사내 AI 입문 교육. 편마다 50분 수업 하나를 기준으로 짰습니다. 모든 도구는 브라우저에서 바로 돌아가므로 설치가 필요 없습니다.

## 공통 진행 방식 — 라운드 토론
1. 라운드 상자를 화면에 띄우고 두 팀의 주장을 읽어 줍니다.
2. 학생들이 손을 들어 USER팀 / 초파리와 features팀 / 둘 다 반씩 중 하나를 고릅니다(30초).
3. 바로 위 실험 도구를 함께 조작해 확인한 뒤, "그냥 판정 보기"로 박사의 판정을 엽니다.
4. "판정을 바꾸려면 조건을 어떻게 바꿔야 할까?"를 한 번 더 묻습니다(조건 바꾸기 습관).

## 1부 활성화 함수 (50분)
| 시간 | 활동 | 도구·라운드 |
|---|---|---|
| 0~5분 | 광고비와 주문 수 질문으로 시작 | 왜 활성화 함수인가 |
| 5~15분 | 뉴런 하나 계산(우산 예), 문만 바꿔 보기 | 도구 1, 라운드 1 |
| 15~25분 | 문 없이 뉴런만 늘리기 → 직선 | 도구 2, 라운드 2 |
| 25~35분 | 포화와 멈춘 뉴런 | 도구 3·4, 라운드 3·4 |
| 35~45분 | 마지막 문 고르기, 대결 | 도구 5, 라운드 5·6 |
| 45~50분 | AI 판단 코너 토론, 퀴즈 | — |

## 2부 연구실 반응속도 대회 (50분)
- 학생마다 종목 ① 속도 기록이 다르게 나옵니다. 기록을 모아 "왜 기기마다 다를까?"를 토론하세요.
- 종목 ②에서 출발 가중치를 "고정 0.05 → 표준 → He"로 바꿔 순위가 바뀌는 것을 함께 봅니다.
- 재경기 표의 평균·범위로 "차이가 흩어짐보다 작으면 비슷하다"를 정리합니다.

## 3부 역전파 (50분)
- 손계산(x=2, w₁=1.5, w₂=2, y=5 → dL/dw₁=8)을 칠판에 먼저 쓰고 도구 3으로 확인합니다.
- 도구 2 "실제로 재 보기"를 반 전체가 동시에 눌러 흔들기/역전파 배수를 비교합니다.
- 대결은 예산을 600 → 4800으로 바꿔 가며 세 곡선이 어떻게 벌어지는지 봅니다.
- 토론 질문: "역전파를 안 쓰는 문제를 우리 회사(학교)에서 하나 찾아보자."

## 실전 연습장 (20~30분, 과제로도 가능)
- 미션 9개 통과 화면을 캡처해 제출하는 과제로 쓸 수 있습니다. 기록은 저장되지 않으므로 캡처를 받으세요.

## 주의
- 숫자는 모두 설명용 모형(시드 고정)입니다. 실제 모델 성능으로 소개하지 마세요.
- 독자를 부르는 말은 "처음 오신 분", "여러분"으로 통일되어 있습니다.
